# TelaViva

Plataforma SaaS de digital signage para publicar fotos e vídeos em TVs gerenciadas por celular ou computador.

## Desenvolvimento local

```powershell
npm.cmd install
npm.cmd run dev
```

- Painel: `http://localhost:3000`
- Login: `http://localhost:3000/login`
- Player: `http://localhost:3000/tv`

Consulte `DEPLOY.md` para publicar e `SECURITY.md` para o checklist de segurança.
